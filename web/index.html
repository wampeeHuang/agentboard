设计原则 →
01
想看状态？打开就有
绿色 = 运行中，灰色 = 未启动。"打开中"说明正在用，"打开"说明可点开用。
02
想控制？点按钮或走 MCP
人点按钮，Agent 走 MCP JSON-RPC 协议。同一套工具，两个平面，共享 manifest 真相源。
03
想加工具？告诉 Agent
Agent 写入注册文件，工具架自动扫描发现。不需要人碰配置，刷新即出现。
04
文件即注册，无数据库
一个 manifest.json 就是一个工具。没有中心配置，没有 YAML 编排文件。删掉文件夹即下架。
