# 换行即设计：视觉节奏的最小单位不是像素，是换行

type: design
date: 2026-08-01
source: 版式画廊品牌套件排版打磨 + 长文本视觉节奏讨论

## 是什么

文字排版中，换行位置对视觉节奏的影响 > 字号/行距/字距。长行 = 读者在行末迷路，短行 = 碎片化阅读。控制每行字符数 = 控制阅读速度。

"换行即设计"——不是排版做完再加的细节，而是排版决策本身的载体。

## 怎么用

### 检查清单

1. **数字出来之前先看行宽**：改字号之前，先问"这一行多少个字？"
2. **CJK 黄金区间**：中文正文 18-32 字/行，英文 50-75 字符/行。标题更少。
3. **极端行宽体检**：找出整个页面最长的一行、最短的一行——差距不能 > 2:1
4. **换行决策 > 字体选择**：读者感知到"读起来舒服/不舒服"首先来自行宽，不是来自字体

### 关键直觉

```
好:  「设计师的工作不是让东西看起来漂亮，
      而是让东西以它应该的方式运作。」      ← 18字，一口气读完
差:  「设计师的工作不是让东西看起来漂亮，而是让东西以它应该的方式运作，并且在这个过程中不引起任何人的注意。」  ← 42字，行末视觉迷路
```

## 案例

**版式画廊品牌套件页**：排版标本区域，AI 生成的示例文字用的是长段落。实测发现长行（40+ 字）在品牌套件的窄卡片里很难读。不是字号的问题——12px、14px、16px 都试了。是把段落切成 18-22 字/行之后，同一字号立刻变得"好读"。

**不用这个原则之前**：调整字号、行距、字距——三个变量来回试，总觉得"差点什么"。
**用了之后**：先定行宽（多少字/行），再选字号。只调两个变量，更快收敛到好结果。

## 边界

- 不适用于标题（短文本，换行点由语义切分决定）
- 不适用于代码（代码的换行由逻辑结构决定，不由可读性决定）
- 英文和 CJK 混排时，以 CJK 计数为准（一个汉字 ≈ 2 个英文字符的视觉宽度）

## 来源
