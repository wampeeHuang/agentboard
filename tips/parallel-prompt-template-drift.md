# 并行 prompt 模板漂移：兄弟模板各自迭代后关键约束不一致
type: diagnosis
date: 2026-08-02
source: 趋势深读评分 7.9-9.1，AI新品评分正常 3.5-4.0——两个 prompt 从同一骨架分化后分数范围约束不同步

## 现象
`gate-ai-signal.md` 产出的 score 在 1-5 范围，`gate-deep-read.md` 产出的 score 在 8-10 范围。
两个 prompt 从同一 Gate 架构模板（`gate-common.md`）派生，各自独立迭代。
AI新品补了 `四维评分（1.0-5.0）` 约束，趋势深读没补。

## 根因
兄弟模板分化后没有同步机制。关键约束（评分范围）写在各自主模板里，不在 `gate-common.md`。
模板 A 的迭代不会自动同步到模板 B。

## 修复
1. `gate-deep-read.md` 补评分范围 `1.0-5.0` + 加权公式
2. 历史数据 score ÷2 修正

## 预防
- **新增跨模板约束时，先问：这个约束应该进 common 还是各自模板？**
  判定标准：≥2 个模板需要 → 进 common；仅一个模板需要 → 进各自
- **兄弟模板定期 diff**：评分维度/格式约束/语言要求等，diff 出差异后逐条判断是故意分化还是遗漏
- **评分/格式/语言/编码 四类约束天然是 common 的**——不进各自模板
