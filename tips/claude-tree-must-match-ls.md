# CLAUDE.md 目录树必须对齐 ls 物理顺序

## 现象

Agent 读 CLAUDE.md 的目录树后，按名字在文件系统找不到文件。
或者用户打开文件管理器，发现树和实际顺序不一致，信任破裂。

## 根因

AI 习惯按"逻辑顺序"写树(入口文件→槽位目录→其他)，但文件系统
按字符排序。两种顺序不一致时，读者在两者之间切换的成本极高。

## 修复

写完 CLAUDE.md 树后，跑一行验证：

```bash
ls -1a | grep -v "^\." | grep -v "^$"  # 或 ls -1a 全量
```

确保树的 ├── 条目顺序严格匹配 `ls` 输出。

## 预防

宪法模板固化：目录树节注释写 `<!-- 顺序: ls -1a -->` 提醒自己。
树只描述存在的东西，不描述"应该存在"的东西。
