# 命题漂移：研究杀死原始命题后，降级方案被包装回原术语
type: capability
date: 2026-07-10
source: cross-border-arbitrage v7→v8 命题修正

## 现象

调研项目"跨境内容搬运套利"——研究阶段用25条实证数据证明纯搬运（L4-L5翻译/直搬）在B站已死。执行计划阶段，Agent 把三个**二次创作/原创**方案（PD素材重组+AI配音、stock图片+解说、地图动画+原创脚本）写成执行计划，全程自称"搬运"。用户（PM）一眼识破："天呐 都是原创 没有搬运呀？"

## 根因

1. 项目名称（"搬运套利"）形成锚定——Agent 延续项目名，不质疑方案是否符合原始定义
2. 研究杀死原始路径后，Agent 自动选择"还能做的最近似方案"（L0-L1素材重组），但不标注这是降级/替代路径
3. Agent 缺乏"命题一致性"自检——不会主动问"这个方案还符合最初对'搬运'的定义吗？"

## 修复

1. 命题诚实化：从"搬运套利"修正为"素材重组套利"
2. 每个方案标注实际性质：O1=L1素材重组，O2=二次创作，O3=原创
3. CLAUDE.md + 执行计划 + HANDOFF 同步更新

## 预防

调研→执行转换时加一道门禁：**方案 vs 命题一致性检查**。逐方案问："这个方案如果让一个不知道项目名的人看，他会说这是搬运还是二次创作？" 答案不一致 → 要么改方案，要么改命题，不能两个都留着。
