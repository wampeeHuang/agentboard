# 飞书多维表格不适合做定价计算层

type: architecture
date: 2026-08-01
source: 德城BOM报价，定价公式表→物理封装表link+lookup+formula链断裂

## 现象

物理封装表中 `固定点位值(公式)`、`点位值(计算)` 等公式字段大量报错（感叹号），根因是 `L_点位公式` link字段缺失导致整个公式链断裂。

## 根因

飞书的 link → lookup → formula 模型只适用于单层简单引用。一旦进入多条件叠加：

```
工艺(贴片/后焊/手焊) × 面数(单/双) × 批量阶梯 × 分类费率 × 一次性费用
```

就会变成：
- 300字符的嵌套IF公式，无人能读
- link字段缺失 → 整条公式链静默爆炸（无报错，只显示感叹号）
- 改一个参数 = 改公式文本 = 不敢改

## 正确分工

| 层 | 工具 | 职责 |
|---|------|------|
| 参数配置 | 飞书表格 | 人改，有修改历史，肉眼可见 |
| 计算引擎 | Python脚本 | 代码可测试、可追溯、可审计 |
| 结果展示 | 飞书表格 | 分组/筛选/导出，人看 |

## 判断标准

问自己：这个计算逻辑能用 `if/elif/else` 三层以内写完吗？
- 能 → 飞书公式可以
- 不能 → 用代码，飞书只做I/O
