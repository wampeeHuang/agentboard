# sqrt修正时间衰减指标偏差

type: pattern
date: 2026-07-21
source: 猫波信号站选题门禁收紧

## 现象
`views / days`（播放/天）指标系统性歧视老数据。一个300天前发的老视频88k播放算出来v/d=240，一个新视频5天2.5k播放算出来v/d=500——新视频看起来比老的好，实际上差了35倍播放量。

## 根因
线性公式 `总量/天数` 假设每天等量累积。现实是指数/幂律衰减——前两天冲高，之后进入长尾。天数权重是1:1线性增长，但实际播放是指数下降。

## 修复
`总量 / POWER(天数 + 1, k)`，k < 1 补偿时间衰减。通用值 k=0.5（sqrt）适用于大多数内容平台（YouTube、B站、公众号）：

```
旧: views / days           → 老视频=240, 新视频=500（错误）
新: views / sqrt(days)     → 老视频=4601, 新视频=1136（正确）
```

k=0.5 是经验值，可根据平台特性调整（0.3-0.5）。+1 防止新发内容分母为0。

## 预防
任何"总量/时间"类指标在应用到不同年龄的数据时，先问：累积是线性的还是衰减的？如果是衰减，开根号是最小可行修正。
