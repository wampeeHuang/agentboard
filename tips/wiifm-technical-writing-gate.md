# WIIFM 门禁：技术文档写作前自检

## 现象
写技术文档直接进入"怎么做"，读者看完不知道能得到什么。用户反馈："扑面而来就开始教我做事，连告诉我做的事是什么都不知道"。

## 根因
AI 默认从"实现细节"组织信息，因为训练数据中技术文档大多是 how-to。作者脑中有完整上下文，默认读者也有——但读者是空手来的。

## 修复
任何超过 100 行的技术文档，第一屏必须有 WIIFM 清单：
```
**看完这篇你能带走什么：**
- 具体承诺 1
- 具体承诺 2
- 具体承诺 3
```

每条承诺对应后文一个板块。写完自检：遮住第一段，问自己"看完我得到什么"。答不上来 = 重写开头。

## 预防
文档任务第一步：列出 3-5 条读者看完能得到的东西。写不出来 = 需求还没理解透，不要开始写正文。
