# 飞书公式字段 TODAY() vs 录入时间

## 现象
飞书公式字段 `[YouTube播放量]/(DAYS([录入时间],[视频发布日期])+1)` 的值在记录创建后就不再更新。老记录的v/d永远停在录入那天。

## 根因
`[录入时间]` 是系统字段 `created_at`，记录创建时写入一次就不再变。`DAYS(录入时间, 发布日期)` 是一个固定差值——不会随着真实时间推移而变化。而 `TODAY()` 每次打开表格都取当前日期。

```
录入时间 → 冻结在创建时刻 → 老记录值永不更新
TODAY()  → 每次动态计算   → 所有记录实时反映
```

## 修复
所有需要随时间更新的公式字段，一律用 `TODAY()` 替代 `[录入时间]`：

```
旧: /(DAYS([录入时间],[视频发布日期])+1)
新: /(DAYS(TODAY(),[视频发布日期])+1)
```

## 预防
创建公式字段时自问：这个值应该跟随真实时间变化吗？是 → TODAY()；否（快照值，如"录入时的播放量"）→ 手动字段。
