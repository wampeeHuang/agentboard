# 孤儿维度：字段存了但没视图展示，vocab 必然静默漂移

## 现象
agentboard 新增工具面板"分类归属"下拉含 `AI托管`，实际只有一个工具用它。列表四维筛选（功能分类/运行位置/接入形态/状态）里根本没有"归属"维度。owner 字段的取值在 4 处各自为政：schema 枚举 `自建|外部|AI托管`、面板下拉、MCP 文档、routes 帮助文案 `外部|自建|内部|AI托管|空=未标注`——三套 vocab 并存，没人发现，因为 owner 不在任何界面展示。

## 根因
维度分两种：**展示维度**（卡片显示/筛选/审计）和**存储维度**（manifest 字段）。存储维度如果不在任何视图出现，就是**孤儿维度**——取值集合没有治理者，任何人都能往里塞值，vocab 在文档/面板/schema/数据四处分裂。漂移不发声：字段不渲染，报错没人看，腐化静默累积。

## 修复
1. **决策：展示或删除，不留中间态。** owner 不在列表任何视图 → 判孤儿 → 从面板删下拉，对齐列表三维。
2. **降级而非硬删**：owner 从 REQUIRED_ALL 移出（可选），schema 枚举删 `AI托管` 留 `自建|外部`。旧 manifest 保留字段，校验只在赋值时查枚举。
3. **全链路 sweep 残留 vocab**：schema 枚举 → 面板 HTML → 前端常量 → MCP 文档/参数 → routes 帮助 → README → 实际数据。grep `AI托管` 归零才算完。唯一使用者（pasteex）迁移到合法值。
4. **派生值不落库**：运行位置（本地/远程）从 type/apiBase/本地进程推导，面板只显示不存储——落库 = 派生值二次真相源。

## 预防
- 新建字段前问：**这个字段出现在哪个视图？** 答不上来 = 孤儿，要么建视图，要么别建字段。
- 删除维度时 grep 全仓库 sweep 该 vocab（schema/面板/MCP文档/帮助/README/数据），grep 归零才算完。
- 面板可选值与列表筛选必须同源同构：面板能选的每个值，列表必须能筛；列表筛的每个维度，面板必须能填。
