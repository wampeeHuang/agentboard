# 空状态文案：不掩饰不辩解，"还在准备"比"暂无数据"更诚实

## 现象

新产品的列表/网格/精选区是空的。本能反应：掩饰（"加载中…"）或辩解（"我们已经跑了三轮测试"）。两种都让读者觉得你在心虚。

## 根因

空状态是产品诚实度的试金石。掩饰 = 撒谎，辩解 = 自证。广告原则⑤（弱点即风格）：你的缺点就是你的风格——如果你真的在认真筛，就说"在筛"。

对比：
- "暂无数据" → 暗示应该有但没有，读者怀疑产品没在运营
- "加载中…" → 撒谎，明明不是加载是空的
- "第一批还在筛。不急。" → 诚实面对过程，不赶、不装、不道歉

## 修复

三步：
1. 承认当前状态（"还在筛"/"还在整理"/"还在写"）
2. 给一个时间感的词（"第一批"/"快了"/"差不多了"）——不承诺 deadline，但让人知道有进度
3. 收在情绪锚点（"不急"/"好了告诉你"/"先看看别的"）——主动权还给用户

## 预防

- 任何 `display:none` 的空状态组件 → 先读它的文案 → 问：这是在说实话还是在圆谎？
- 空状态不走"暂无"系措辞——"暂无"是数据库语言，不是人话
- 检查清单：空状态文案是否可以用在真实对话里？如果对朋友说不出口（"暂无精选模板"），就不应该对用户说
