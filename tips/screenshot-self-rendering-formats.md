# 截图在自渲染格式下不是质量证据

## 现象

用截图论证 HTML 模板的质量——"截图验证代码声称 vs 浏览器实际"。被追问后发现 HTML 本身就是可渲染的，人对 HTML 和截图没有信息差。截图唯一不可替代的价值是作为 vision API 的输入原料（像素格式）。

## 根因

把"机器管道的输入格式"和"质量验证的证据"混淆了。对自渲染格式（HTML/SVG），前者不等于后者。截图 = 照片，HTML = 人——人在那，拍不拍照他都在。

## 修复

分两类判断截图在门禁中的角色：

| 产物类型 | 例子 | 截图是质量物证吗 | 截图的正确用途 |
|---------|------|----------------|--------------|
| 自渲染 | HTML, SVG, PPTX | 不是——打开就是渲染结果 | UX 便利品 / vision API 输入原料 |
| 非自渲染 | 代码生成图, 3D, 视频编码 | 是——渲染结果不能直接观测 | 质量物证 |

## 预防

设计质量门禁时先问：**产物本身能否被直接观测？** 能 → 不需要截图做质量证据。不能 → 截图是必需品。
