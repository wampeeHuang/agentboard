# 对比页绑定项目立场，check.js 拦不住
type: diagnosis
date: 2026-08-08
source: D:\Obsidian\wiki\对比\PCBA 在线报价系统对比.md 重写

## 现象
对比页文件名"竞品调研"、正文"最成熟的""最值得借鉴的""可学"，check.js exit 0 全部通过。用户一眼识别不合规。

## 根因
check.js 只验结构（frontmatter/标签/交叉引用），不验语义。"竞品"隐含特定项目立场——有竞品就有"我方"，绑定项目视角的内容不可泛化，违反"泛化与实例物理分离"原则。评估性语言同理："最成熟的"预设了评判标准，"可学"预设了读者立场——都不是客观比较。

## 修复
1. 去"竞品"、去"调研"——标题和正文不出现项目立场词
2. 删评估性语言：最高级形容词、可学/值得借鉴/推荐
3. 自检：这篇文档换一个项目/读者/时间，结论还成立吗？不成立 → 项目立场没摘干净

## 预防
写对比页前过 quality-gates 问 3（页面类型对吗？）+ 自问"有项目立场词吗"。对比页 = 客观并列，不为任何项目服务。
