# TTS 错读生僻字：配音文本换同音常用字，显示文本不动

## 场景

IndexTTS2.5 把「掼」(guàn) 念成 san。若文案、字幕、TTS 共用一份文本，改读音就得连显示一起改。

## 步骤

1. 正稿不动：script.json / 字幕 / 交付文案继续用原字（掼）。
2. 只在生成 TTS batch 输入时做单向替换：掼→惯（惯=guàn，高频字，模型读音稳定）。替换只进 TTS 输入文件，不回写正稿。
3. 选字标准：与目标读音同音同调、字频高。多音字慎用。
4. 重配音后抽听确认。

## 边界

- 只救单字错读；整句韵律错误换字无效，回 TTS 参数层排查。
- 替换表随项目落在 _runtime，重建 batch 时复用，避免每次手改。
