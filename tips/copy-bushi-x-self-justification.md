# "不只是X"是自证陷阱——不是在宣誓，是在辩解

type: diagnosis
date: 2026-08-10
source: Layout Gallery 首页文案——"不只是好看/不只是承诺/不只是模板"被用户第一眼诊断为自证模式

## 现象

产品文案写"不只是好看""不只是快""不只是便宜"——写的人觉得在破除刻板印象、强调差异化。读者感受到的是：你在辩解。你在回应一个没人提出的质疑。

## 根因

"不只是X"的逻辑结构是：先承认X存在 → 再否认自己只有X。问题在**第一步就输了**——你主动把负面联想（"你们只是好看而已"）植入了读者脑中。

对比 Avis 的"We Try Harder"：不说"我们不只车少"，说"我们是第二所以我们更努力"。把弱点直接摊开，变成承诺——不是在辩解"我也有大的"，是在宣誓"我就小，但我更拼"。

中文语境更敏感：中文"不只是X"的语调天然带防御感——"我不只是好看" = "你觉得我只有好看" = 你在跟想象中的批评者吵架。

## 检测方法

```bash
grep -rn "不只是" --include="*.html" --include="*.md"
```

每一条命中都问：这是在破除读者真实存在的误解，还是在跟空气打架？如果读者没这个误解，删掉。

## 修复

不只是X → 直接说Y。把辩解句改信念句：

| 旧（辩解） | 新（宣誓） |
|-----------|-----------|
| 不只是好看，还有实力 | 每个版式都经过真实内容测试 |
| 不只是快，还稳定 | 三次独立评测，全部通过才上线 |
| 不只是便宜，还耐用 | 买一次，用十年 |

不想删？在保留前自问：Avis 会写"我们不只车少"吗？不会。为什么你要？

## 预防

- 文案评审 checklist 加一条：grep "不只|不仅|不止" → 命中即自证嫌疑 → 删或改
- 写完任何产品标语，问：这句话会在一个没人质疑我的世界里说吗？如果在辩解，重写
