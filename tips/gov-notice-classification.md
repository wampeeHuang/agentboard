# 政府公告巡检：认定≠配租

## 现象
AI agent 巡检政府公告时，见到"保租房"三个字就当可申请报。实际公告只是项目认定（发认定书），项目还在施工，没开放申请。

## 根因
政府公告有四类，AI 容易混淆：
- **项目认定公告**（给开发商发认定书）→ 不能申请
- **配租通告**（面向公众招租）→ 可以申请
- **认租结果/选房公告**（已结束）→ 已过期
- **草案/征求意见稿**（未生效政策）→ 不能按正式政策引用

AI 倾向见到领域关键词就触发"有更新"判断，不做公告类型判别。

## 修复
1. prompt 硬编码四种公告类型，每种标注对应动作（认定→记录追踪/配租→通知用户/结果→标注过期/草案→标注未生效）
2. 每条动态区分"公告原文写了什么"和"通用政策是什么"，通用政策引用法规编号
3. 未竣工项目强制标注"施工中，暂不可申请"
4. 媒体标题只作线索，最终以官方公告原文为准

## 预防
任何政府公告/政策巡检类 cron job，prompt 必须包含公告类型判别表。不依赖 agent 自行判断公告性质。
