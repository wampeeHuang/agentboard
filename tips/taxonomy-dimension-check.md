# 分类维度同层检查

## 现象

9 个模板平铺成同级列表，但 T2（Claude 入口）、T3（跨 Agent 兼容）、T5（人机双读者）是叠加于任何项目之上的适配层，而 T1/T4/T6-T9 是互斥的项目骨架类型。读者困惑"选一个还是叠加上去？"

## 根因

适配层（AND 关系——可叠加多个）和实体类型（XOR 关系——选一个）不是同一分类维度。把它们放同一张平表里，等于把"你要装什么操作系统"和"你要不要装杀毒软件"列成同级选项。

## 修复

1. 列表加维度标注列，标明每个条目是"入口适配层"还是"项目骨架"
2. 拆成两道独立决策：先选骨架（XOR），再叠适配层（AND）
3. 决策流程图已体现这层关系（T5 用虚线标注"适用于以上所有"），列表需要同步

## 预防

列出 N 个同级选项前，问两个测试问题：
- **"它们之间是互斥选择还是可以叠加？"** → 有叠加关系 = 不在同一维度
- **"删除其中一个，其他选项的含义会变吗？"** → 不会变 = 可能独立维度

有叠加关系的条目，要么拆成独立决策步骤，要么加维度标注列。
