# 用户说"不理解"时，停掉一切工程操作，切换到费曼模式

## 现象

用户明确表达困惑（"我不理解""这么难理解""你能当我老师吗"），但 Agent 继续在工程层面解决问题——修 bug、跑数据、调架构。

## 步骤

触发词：用户说"不理解""看不懂""费曼""当我老师""从零讲"。

1. **停掉所有工程操作。** 不修 bug，不讨论架构方案，不写代码。
2. **从零开始讲。** 假设用户对这个领域一无所知。不用术语，不引用"之前讨论过的"。
3. **用最朴素的语言构建心智模型。** 一页纸、一张表、一条计算链。数比字有说服力。
4. **等用户说"我懂了"再继续工程工作。** 确认理解后才能回到方案讨论。

## 为什么

用户说"不理解"时，最差的回应是继续在当前抽象层操作。这时候用户需要的不是解决方案，是理解——没有理解就没有判断，后续所有方案讨论都是在沙子上盖楼。

## 预防

对话中检测到困惑信号时主动问："要不要我从头讲一遍这个机制？"不等用户明确求助才切换。
