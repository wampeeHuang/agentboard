# 知识层级：靠结构不靠标签

## 现象
Agent 在概念页每个小节开头加"层级：架构基础。"、"层级：空间内的导航机制。"等显式标签，被驳回。用户："要这样生硬定义吗？这是内化的规则。"

## 根因
Agent 不确定读者能否理解层级 → 加元注释标注 → 违反"内容页纯净原则"（内容页只陈述知识，不写元注释）。用治权语言污染了知识内容。

## 修复
层级关系通过两种方式内化：
1. **顺序** — 从基础到表层排列，读者读下来的顺序就是层级
2. **首句定位** — 每节第一句话说明本节在整体中的位置（"Vault 治理的架构基础。定义了两个不可互换的空间..."）

不靠标签，靠结构自己说话。

## 预防
- 写完概念页后检查：有没有"层级"、"分类"、"注"、"本节"等指向自身结构的词 → 删
- 自问：去掉所有粗体标注后，层级关系还能从顺序和首句读出来吗？不能 → 调顺序，不加标签
