# 验证门禁空转仍返回成功：安全网没检查 = 没有安全网

## 现象
链尾目录检查遍历产出目录做验证，但因为标记了"有失败"，全部目录被跳过（log 显示 `3 failed-skip, 0 to check`），进程仍返回成功码。状态面板全绿，实际产出从未被真正验证过。

## 根因
跳过逻辑返回了"成功"，没返回"跳过"——门禁把"跳过"和"通过"混为一谈。用户以为被保护，实际安全网空转。比报错更危险：报错有人修，空转没人知道。

## 修复/步骤
1. 检查跳过原因的合法性——"跳过是因为上一次残留失败"本身就是 bug，先修根因（状态清零，见 `state-failure-list-never-cleared.md`）
2. 让跳过可见：日志必须输出 `skipped N / verified M`，不能只有通过
3. 门禁层加"0-skip 断言"：跳过项必须带理由，无理由的跳过算失败

## 预防
- 门禁的每个"通过"必须基于真实检查。跳过/SKIP/N/A 不算通过，跳过必须带理由
- 汇报用"验证了几个/跳过了几个"数字，比"通过了"可信
- 安全网的关键属性不是"报错时挡得住"，是"没检查时挡得住"
