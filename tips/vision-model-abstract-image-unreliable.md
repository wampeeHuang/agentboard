# 视觉模型判"抽象/调色"变化不可靠，照片类才可信

## 现象
用视觉模型（DeepSeek vision）验证 shader 效果是否生效：对一张完全反转颜色的抽象图，模型判"画面没有变化"；但对照片类图像，反转、压暗等效果都能正确识别。抽象图上的视觉结论不能当证据。

## 根因
视觉模型擅长"画面里大概有什么、什么氛围"的粗粒度判断，对抽象图形、纯色块、调色矩阵这类没有语义内容的变换，感知阈值高到连明显反转都读不出变化。置信度与正确率无关。

## 修复/步骤
按图类选验证手段：
1. 抽象图/调色类 → 像素统计（均值、直方图、diff 比例），不用视觉模型
2. 照片类 → 视觉模型可作证据
3. 拿不准属于哪类 → 先跑像素 diff，diff>阈值再看图

## 预防
批量视觉验证前先按"有没有语义内容"分图类。抽象类先做像素统计，视觉模型只留照片类。与 `vision-llm-ocr-unreliable`（别用视觉模型读精确文本）互补。
