# 引语精选禁编造过渡句——即使是"无害桥接"

## 现象
写引语精选文章时，在两条引语之间加过渡句（"但他说了一句不平凡的话""涨价有理有据。但他降了。""这不是话术"），用户反复指出这些句子不在任何源稿中。

## 根因
引语精选和原创评论两种文体混用。读者无法区分"梁文锋说的"和"作者加的"。即使是"但他说了一句不平凡的话"这种看似无害的桥接句——它暗示梁文锋说了不平凡的话——但这个判断来自作者，不是源稿。

## 修复/步骤
引语精选只用编号+引语本身，不写任何过渡、解读、桥接。

```
✅ 正确:
**1.**
我们两年前成立这个公司的时候，没有很多钱...

**2.**
AI这个事情足够大，最终可能占掉...

❌ 错误:
**1.**
我们两年前成立这个公司的时候，没有很多钱...
但他说了一句不平凡的话——
**2.**
AI这个事情足够大...
```

注释只能在引语块外部（前言/后记），不在引语之间。

## 预防
- 写完引语精选后 grep 引号外的中文句号/感叹号——很可能就是编造的过渡句
- 自问：这句话是梁文锋原话，还是我写的？后者=删
- 每个条目交付前验证：编号→引语→编号→引语，中间无其他文字
