# 管线闸门只信任系统控制字段
type: anti-pattern
date: 2026-07-29
source: 猫波信号站 日期漂移 bug — sync_feishu_to_curation.py

## 现象
管线用飞书"视频发布日期"字段做二次过滤，日期被人为/自动化改动 → 记录匹配到错误的 curation date → 已策展视频被重复处理，旧工作被新目录覆盖。

## 根因
飞书是人可编辑的 UI 层，人犯错是常态。管线闸门只能用系统控制字段（状态机），不能用可编辑字段。

## 修复
移除 date-scoping 逻辑。飞书 FILTER 用状态字段（候选/待发布）限定范围已足够，不再加日期过滤。

## 预防
- 管线过滤条件检查：每个过滤字段问"这个字段人能不能改"
- 人能改的字段 → 只能用作展示/富化/参考，不能用作闸门
- 闸门字段来源：流水线自动写入的状态机，或不可变字段（created_at）
