# 本地 HTML 的 href="/" 会跳到磁盘根目录

type: capability
date: 2026-07-14
source: 德城科技 B2B 官网本地调试

## 现象
本地浏览器打开 `index.html`，点击 logo 或链接跳到 `D:\` 或 `C:\` 文件列表。

## 根因
`href="/"` 在 `file://` 协议下解析为文件系统根目录，不是站点首页。HTTP 服务器上才解析为域名根路径。

## 修复
本地开发阶段用 `href="#"` 或 `href="./"`。部署到服务器后改回 `href="/"`。

## 预防
本地预览的 HTML 链接用相对路径，部署阶段通过构建脚本替换为生产路径。
