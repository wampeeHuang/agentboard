# 跨站共用组件调 API：200 但编辑表单全空

## 现象

工具架(3099)点卡片「编辑」→ 表单全空，标题/类型/分区都不回填；调度中心(3100)同操作正常。HTTP 200，curl 直连接口能拿到完整 md。

## 根因

组件用 r.json() 解析详情接口响应。工具架 /api/tips/:file 返回 text/plain 裸 md，json() 对裸文本抛 SyntaxError → 进 catch 提示加载失败，表单停在默认空值。两站接口返回形状不同（调度中心 JSON 包 content，工具架裸字符串），组件却假设同一形状。返回 200 不等于解析成功——状态码正常掩盖了形状错位。

## 修复

组件改为 r.text() 读原文 → 先 JSON.parse 尝试，失败就当裸 md 字符串，统一交给 normBody。调度中心 JSON、工具架裸文本两条路径都走通。

## 预防

跨站共用同一组件对接多个后端时，把「返回形状」当接口契约显式对齐，别假设各站一致；或一律用自适应解析（text+JSON 双兼容）而不是固定 r.json()。同类错位还出现在文件名参数带不带 .md 后缀——跨站对接时一并核对。
