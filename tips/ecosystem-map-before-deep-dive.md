# 生态地图先于深度分析

type: pattern
date: 2026-08-10
source: 2026-08-10-graph-engineering-wiki 复盘

## 现象
多选项对比类文档深入讲解 3 个选项，但读者连一共有多少选项、谁活着谁死了都不知道。用户反馈："连全局全貌有多少种都不知道，就已经开始教大家怎么搭了"。

## 根因
分析型思维（深度 > 广度）与探索型需求（先要地图再要深度）的冲突。AI 天然倾向"挑几个重要的深入讲"，但读者认知路径是"地图 → 定位 → 深入"。

## 修复
对比/选型/调研类文档的门禁：不出现全局分类地图之前，不进入单项深度分析。
- 第一屏：所有选项按类别 + 状态标注（🟢活跃 / 🟡小众 / 🔴维护模式）
- 第二屏起：深入分析重点选项

## 预防
多选项文档写完第一段后自检：读者看完这一段，能画出这个领域的"地图"吗？不能 = 补地图再往下写。
