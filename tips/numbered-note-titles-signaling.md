# 复杂笔记标题打序号，利用数字标记效应增强阅读脉络
type: method
date: 2026-08-11
source: 写 Agent 流水线文件架构范式深度拆解时发现——给主文章和子笔记打上序号后脉络清晰很多

## 规则

多篇有递进关系的复杂笔记，标题前缀加序号。不是所有笔记都加——简单笔记、独立概念笔记不需要。

## 为什么有效

对应四条认知原理，不是个人偏好：

| 原理 | 对你读者的作用 |
|------|---------------|
| **数字标记效应**（Lorch & Chen, 1986） | 看到 `01-` `02-` 时，大脑自动分配更多注意力给标记项。数字成为检索线索——读完更容易回忆"第几部分讲了什么" |
| **信号原则**（Mayer, 1984） | 明确的序列信号降低外在认知负荷。读者不自己推断"这几篇什么关系"，认知资源留给理解内容本身 |
| **心理数字线**（Dehaene, 1992） | 人类天生把小数字映射到"先发生/基础"、大数字映射到"后发生/进阶"。这个映射是无意识的——`01-` 自然被理解为入口 |
| **组块化**（Miller, 1956） | 数字把系列笔记分解成空间位置明确的组块。读者脑中形成"总共 N 篇，当前在第 M 篇"的结构表征 |

Lorch & Chen 的核心发现：数字标记不改变读者记住的总信息量，但**显著提升对标记信息的回忆，同时让回忆顺序更贴近原文结构**。换句话说——读者不一定记住更多，但记住的东西更有条理。

## 什么时候加序号

- 主文章 + 多篇子笔记构成递进系列 → 加
- 一篇笔记内部章节有先后顺序 → 章节标题加（如本文 §3.1、§3.2）
- 独立概念笔记、术语卡片 → 不加

## 什么时候不加

- 简单笔记（<200 字，单一概念）
- 无递进关系的并列笔记
- 序号超过 9 时考虑拆系列或换组织方式——两位数序号的心理数字线效应衰减

## 预防

- 序号和内容脱节（`03-` 应该比 `02-` 更进阶，不是并列）→ 检查相邻笔记之间是否有"不读前一篇就读不懂后一篇"的关系
- 序号跳号 → agent 和读者都会困惑"缺失的那篇在哪"
