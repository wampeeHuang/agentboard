# 纯文字替换视觉内容永远是降级

## 现象

用户要"把工具目录改成有案例的故事"。方案是新建 3 个纯文字 section（一小段介绍+外链），替代原有的卡片+iframe 预览布局。用户反馈："都是文字 不如没有 回退吧".

## 根因

原有卡片结构 = 截图/iframe + 标题 + 描述 + KPIs。视觉内容（截图/iframe）承载大量信息——用户一眼能看到产品长什么样、是不是真的。纯文字 section 把视觉内容拿掉了，信息量反而下降。

## 修复

不新建纯文字区块替代已有的视觉内容。正确方向：
- 在现有卡片上做视觉增强（更大预览图、精选标记）
- 重新排序——把核心案例卡片往前放
- 不改结构的前提下调文案语气

## 预防

设计重构方案时自检：新方案的信息密度（视觉+文字）是否 ≥ 现有方案？如果答案是否，方案不合格。
