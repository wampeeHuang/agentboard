# 免费商用中文字体几乎只有单一字重 Regular，font-weight 是合成的

## 现象
卡片上想给不同字体设"字重 常规/粗体"，发现大多数字体只有 400 一档。设 `font-weight:700` 无对应字体文件，浏览器用 font-synthesis 合成加粗，笔画糊、字形走样，质量参差。

## 根因
造字成本：中文常用字 3500+，每个字重整套重画。免费商用 CJK 字体基本只发布 Regular（400）一档，个别带 Bold（700），更细的字体分级（Light/DemiBold 等）罕见。

## 修复
- 字体选择器只展示"是否有真实 Bold 档"，不承诺可调字重
- 需要"粗一点"视觉效果时，优先换一款天生粗体的字体（如标题体），不用合成加粗
- 合成加粗（font-synthesis）仅作应急，UI 上标注是合成效果

## 预防
设计含 CJK 字重的 UI 前先扫目标字体集的重量表（fontTools 扫 `name` 表 Weight 字段）。默认假设"单一字重"，把"可调字重"当稀缺能力而非默认能力。
