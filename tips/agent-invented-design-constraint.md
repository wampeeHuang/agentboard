# Agent 不要自创设计约束，用户给的规格直接落地

## 现象
AI 做 UI 时按自己的审美补充约束，被用户连续两次否掉：
- 把卡片宽度 384 误当搜索框宽度改
- 用模拟手机框/自定义内容宽度代替用户给的明确规格（1600 等）

用户原话："谁给你定义我们现在的内容宽度呀""我不需要你模拟手机框"。

## 根因
Agent 把"看起来合理"的设计决策当成了自己的裁量权，替用户定义了产品规格。用户才是设计决策者，Agent 的工作是把用户给的数字落地，不是发明新约束。

## 修复
- 用户给具体数字（宽度/间距/字号）→ 直接应用，不替换、不"优化"
- 用户没给 → 用 CSS 自动适配（auto-fill/minmax/百分比），不引入固定假设
- 改对象前先复述目标："卡片宽度"和"搜索框宽度"是两回事，歧义先确认

## 预防
UI 任务里每个设计参数自问：这是用户给的，还是我发明的？后者先问再动。方案确认前不写代码，规格由用户定，Agent 只做执行与验证。
