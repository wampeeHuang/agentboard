# 飞书公式字段 JSON 传参：中文双引号被转义破坏公式语法

## 现象
lark-cli `+field-create` / `+field-update` 传入含中文双引号 `""` 的公式 expression → Feishu 报"左侧缺少运算符，请补充完整"。公式字段显示空白。

## 根因
公式字符串里有中文双引号，例如：
```
"...或用"（重复）"放在句尾..."
```
经过 JSON 序列化时 `\"` 被转义为 ASCII 双引号 `"`。公式引擎也用 `"` 做字符串定界符，结果字符串被提前闭合：
```
"...或用"（重复）"放在句尾..."
        ↑ 这里字符串断了，公式引擎看到孤立的（重复）
```
公式引擎把 `（重复）` 当运算符/变量解析 → 左侧缺操作数 → 报错。

## 修复
用 `「」`（中文直角引号）或 Unicode 转义代替中文双引号：
```
"...或用「重复」放在句尾..."
```

## 预防
- 飞书公式字段的 expression 里，永远不用 `""`（中文双引号），统一用 `「」`
- 写入前 grep 检查 JSON 文件是否有裸的 `“` `”` 字符在字符串字面量内
- 如果必须保留中文双引号，在公式里用 `CHAR(8220)` + `CHAR(8221)` 拼接
