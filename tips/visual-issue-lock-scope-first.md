# 视觉指认先锁定元素范围，再动手

## 现象

用户指认一个视觉元素（如"logo 垫底用品牌绿"），我用字面在页面上找一个同名元素，在错误范围内改了一整轮；用户纠正"我一直说的是图形图标，没说别的"，随后又让我把误改的另一个节"还回去"。

## 根因

用户用"logo"泛指整套图形系统（logo + 图标 + 图形语义），我按字面锁定页面上唯一叫 logo 的元素。指认词没有映射到具体 DOM 元素就动手，范围错一步，整轮全错。

## 修复/步骤

动手前把用户的每个指认词映射到具体元素，引用当前文案逐条对齐：

1. 把用户消息里每个视觉词（logo / 图形 / 副标题 / 三块卡片）写下来
2. 在 HTML 里 grep 定位到对应 DOM 节点，确认它和用户说的是同一个东西
3. 用当前文案回读给用户对齐（用户会直接说"对"或"我说的是另一个"）
4. 范围锁定后再改，改完只动范围内元素

## 预防

- 用户给视觉需求时，第一句先报"我理解为改 XX 节 / XX 元素"，等确认
- 指认词有歧义（logo、标题、按钮这种泛称）时，宁可多问一次也不要开改
- 若已在错误范围改动，立即回退到原状态，不留自己"觉得更好"的部分
