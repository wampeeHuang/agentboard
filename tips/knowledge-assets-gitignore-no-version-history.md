# 知识资产被 gitignore = 无版本保护：经验日志库差点失去全部历史

## 现象
审计 ~/.agentboard 时发现：`tips/`（当时 443+ 条经验日志）在 `.gitignore` 里被忽略——经验库**完全不在版本控制中**：无历史、不可回滚、无备份。

## 根因
`.gitignore` 里的忽略项往往是"当时顺手加的"（与 tools/ state/ 一起），但**知识资产和运行数据的忽略理由完全不同**：tools/ 是本机个性化数据（合理不入库）、state/ 是可重建运行态（合理不入库），而 tips/ 是长期知识沉淀——它的价值恰恰在"可回溯、可恢复"。用同一条规则忽略了三类性质不同的东西。

## 修复/步骤
1. 从 `.gitignore` 移除 `tips/`
2. `git add tips/` + 提交（445+ 文件一次性入库）
3. 后续每条经验随提交入库，历史即资产

## 预防
- 判断"该不该入 git"看**资产的不可重建性**：可重建的运行数据 → 不入；不可重建的知识/代码/配置 → 必入
- gitignore 里每一条都要能回答"为什么忽略"，且定期审计（tree-drift/inspection 门禁）
- 核心知识库（经验/文档/规则）默认应入版本控制，除非有明确理由
