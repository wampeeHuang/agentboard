# shader 参数超值域=静默失效，默认值可能不是你以为的值

## 现象
给 shader 写参数面板时，有些拉杆拉到底效果却不对：范围类参数拉到 50 应该最强却全屏填充、坐标类参数默认 0.5 却在屏幕角落、亮度类参数默认却是全黑。逐个排查才发现是参数值域和默认值在作怪。

## 根因
1. **超值域静默失效**：shader 内部按声明的 min/max 解释参数，面板给的默认值超出声明值域时，效果变成"全开/全关"，OBS 不报错。
2. **默认值陷阱**：uniform 的默认值决定没设参数时的表现。Luminance 默认 color=[0,0,0,1]（黑）→ 不设参数就全黑。

## 修复/步骤
1. 先读 shader 源码或 uniform 声明拿真实 min/max 和默认值，不要猜。
2. 面板默认值按 shader 声明值域设，不是"拉最大最明显"。
3. 坐标类参数（center_x/y）确认坐标系原点（0.5 可能是屏幕角而非中心）。
4. 测试时逐参数探边界，别只测最大。

## 预防
给 shader 写参数面板前，先跑解析器把每个 uniform 的 min/max/默认值打印出来核对。超值域失败是静默的——不报错，效果直接不对。
