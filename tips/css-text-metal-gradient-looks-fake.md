# CSS 文字金属渐变 = 假

## 现象

`background-clip: text` + `linear-gradient`（多段亮暗交替）模拟金属镀层光泽。看着假，不如 solid color。

## 根因

金属感的核心是一段**极窄高光反射带**（通常 3-5% 带宽），模拟镜面反射的 specular highlight。没有这个窄带 = 普通渐变 = 塑料感。

更深层问题：金属反射需要曲面曲率来建立反射方向——平面文字没有曲面，人脑判定渐变方向与预期反射角不匹配 → "假"。

## 修复

1. **首选：放弃 fake metal。** 用行业锚点色代替。PCBA → 电路板绿 `rgba(58,140,92,0.90)`。金融 → 深蓝。每个行业有自己的"真色"
2. **次选：如果必须金属感。** 用 `radial-gradient` 而非 `linear-gradient`，模拟点光源在曲面上的扩散反射
3. **加微弱 text-shadow。** `0 1px 3px rgba(0,0,0,0.55)` + 同色系微弱光晕 → 比裸渐变有深度

## 预防

- AI 调渐变参数前，先确认每个色标在视觉上的作用。渐变色标 ≠ 冗余 = 不可压缩的信号
- 问一句："这个颜色在现实世界中对应什么？" 电路板绿 → PCB 阻焊层 → 真实。镀层渐变 → 没有现实锚点 → 假
- 文字特效的黄金测试：截图 → 缩小到 50% → 还能看出来是什么吗？
