# AI 产出中文文案的"X，不X"相邻矛盾检测

## 现象

文案写"异常处理：推飞书，不推送。"——读起来像"推送到飞书，但又不推送"。原意是：①异常时推飞书通知，②不等人来看报告。但八个字挤成一句，变成自相矛盾。

## 根因

LLM 读文案按**语义主旨**理解，不按**字面结构**比对：
- 看到"推飞书" → 语义：有推送机制 → ✓ 通过
- "不推送"被理解为"不等人推"而非字面"不推送" → 矛盾被语义补全消解

人对"X，不X"句式天然敏感，LLM 不敏感。这是 LLM 审稿的结构性盲区。

## 检测方法

中文文案交付前跑两条规则：

1. **相邻矛盾检测**：grep 同一句中同时出现"X"和"不X"（且指向同一主体）的模式
2. **朗读测试**：逐句朗读，听到"X，不X"立刻停——这几乎一定是错的

## 预防

- 面向公众的文案 → 交付前朗读一遍，不只看
- 数字/事实断言 → 脚本统计验证，不凭 LLM 直觉
- 同一概念不要在相邻位置既肯定又否定——拆成两句写清楚
