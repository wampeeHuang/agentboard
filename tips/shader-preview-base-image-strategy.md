# 效果预览的底图是实验变量：一张万能图测不出所有效果

## 现象
给 142 个 shader 效果批量生成预览缩略图，用同一张暗色画面当底图，一半效果"看不见"——像素 diff 小于 5%，缩略图跟原图没区别。看似是效果没生效，实际是底图选错了。

## 根因
效果类可视化验证里，底图本身决定效果显形与否。暗底/半透明底图上，压暗、调色、矩阵、选择性类效果的变化被底图自己的暗度吞掉；半透明底图还会让透传类效果整体褪色。

## 修复/步骤
按效果类别选底图：
1. 纯色 16:9 → 边框/圆角/裁剪类（边缘干净利于判断）
2. 内容 16:9（普通画面）→ 透视/裁剪类
3. 亮调照片（高亮度均值）→ 调色/压暗/矩阵/选择性类专用

配套注意：OBS 的 SaveSourceScreenshot 按源原生分辨率出图（不按窗口缩放），别假设固定 1920x1080。

## 预防
批量做效果可视化前，先问"该类效果在什么底图上最显形"，再选图开跑。一批一个底图策略，不追求一张万能图。
