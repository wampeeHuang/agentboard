# 单页领域目录诊断

## 现象
`概念/领域名/` 目录下只有 1-2 个 .md 文件。CLAUDE.md 路由表有独立一行指向该领域。

## 根因
新建概念时按路由建了独立领域目录，但后续没有内容增长。单页领域的维护开销（路由条目、目录结构、check.js 遍历）远超内容价值。

## 修复
1. 移文件到相邻领域目录
2. 删空目录
3. 更新 CLAUDE.md 路由（合并关键词到相邻领域行）
4. `node scripts/rebuild-index.js`

## 预防
建新领域目录前自问：预计 < 3 页？不建，用相邻领域。
门禁：已有领域目录 < 3 页 → 评估合并。1 页无条件合。
