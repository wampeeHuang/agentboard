# 浏览器会话恢复应走最小权限的本地桥接

## 适用条件

本地服务需要复用用户已登录浏览器的某个网站会话，但直接读取 Chrome/Edge Cookie 库被加密、权限限制或多 Profile 状态阻断；要求用户复制 Cookie/token 又容易泄露、过期和出错。

## 步骤

1. 不把“读取不到浏览器 Cookie 库”误判为“平台会话不可用”：先用目标服务的真实健康检查或最小请求验证。
2. 建一个浏览器 Manifest V3 扩展，仅申请目标站点域名的 Cookie 权限与一个明确的 loopback 接收端（如 `127.0.0.1`）。
3. 只在用户点击同步或明确的恢复请求时读取当前域会话；从当前页面 URL 取会话参数时，先校验域名和参数存在。
4. 扩展不把 Cookie/token 写入 storage、控制台、提示文案或公网；接收端也不在日志和 UI 回显秘密。
5. 由最终执行服务显示“已同步/失效/需重新同步”状态，并以真实鉴权调用验收。

## 预防

不要把浏览器插件做成抓取器，也不要让工具架卡承担秘密输入。插件只做认证桥接；抓取仍归执行服务，工具架只登记能力与依赖。
