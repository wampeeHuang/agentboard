# 失败状态只增不清：残留假失败，安全网跟着空转

## 现象
某次运行有候选失败，失败列表写入。之后重跑全成功，状态面板仍显示上次的失败项；同一批 slug 同时出现在"已完成"和"已失败"。下游检查因"有失败"跳过真实目录，返回成功码。

## 根因
失败列表只在失败分支赋值，成功路径从不清空——状态更新不对称。失败状态是**派生状态**，必须反映本轮真相，却累积了历史。

## 修复/步骤
每次运行开始时重置失败列表（`checkpoint["failed"] = []`），让它在本轮内从零构建。已污染的存量数据：重新生成状态面板即自愈。

## 预防
- 任何"失败/完成/跳过"二元状态：写失败分支时必须同步考虑成功分支——成功时清空，绝不保留
- 派生状态（失败列表、状态面板、统计）一律每轮从真相源重算，不累积历史
- 有"失败列表/跳过列表"这类累积字段，先问：成功时它被清空吗？
