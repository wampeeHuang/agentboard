# 动态计算字段与静态源文件的值不一致

## 现象
验证脚本（check.js）读 YAML 文件的 `tier` 字段，和服务器 `/health` API 返回的 tier 分布对比，报 tier_mismatch。但服务器实际运行正确。

## 根因
同名字段 `tier` 在两个地方含义不同：
- YAML 文件里是**静态快照**（写入时的值）
- 服务器 `computeTier()` 根据近 30 天点击数**动态重算** S/A 档位

服务器不读 YAML 的 tier 字段来做展示——它自己算。验证脚本对比了两份语义不同的数据。

## 修复
只验证人类手动设定的字段（此例中 X/block 档位），跳过机器动态计算的字段（S/A）。在 pass 消息中标注"动态计算，以服务器为准"。

## 预防
- 验证脚本和服务器之间，先确认每个字段的**权威来源**是谁
- 同名字段≠同一数据——追问：这个值是写入时固定的还是运行中会变的？
- 无法确定时，读服务器源码看实际读取路径
