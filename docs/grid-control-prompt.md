# 网格控制 UI 原型 · 固定 prompt

> 可复用的原型要求。做像素级对齐的 UI 原型时，把下面 prompt 整段粘贴给 Claude，得到标准网格参考层 + 控制面板（自包含，无需参考文件）。

---

## 使用

```text
给我加一套「网格参考层 + 右下角控制面板」：页面铺一层 8/32/128px 三档网格参考线（左上角为零线），右下角固定一个小面板控制网格开关和档位。按下面规格做，不许改页面已有内容的布局。

【网格层】
- 三层刻度：128px、32px、8px，全部 1px 线
- 颜色：128 实线 rgba(51,51,51,1)，32 半透明 rgba(51,51,51,0.45)，8 淡 rgba(51,51,51,0.2)
- 疏的实、密的淡——大格最清晰，小格最淡，叠着看不糊
- 定位：fixed 铺满全屏 inset:0，pointer-events:none（不挡点击），z-index 放页面之下（-1），background-position:0 0（左上角为零线）
- 实现：用多个 linear-gradient 组合成背景（每条管一个方向一行刻度），不用 DOM 网格元素

【控制面板】
- 固定右下角 right:16px bottom:16px，高 32px，白底，1px 边框，圆角 8px，浅阴影，z-index 80
- 结构：左「网格」字标 → 开/关按钮 → 「·」分隔 → 三个档位按钮 8 / 32 / 128
- 档位按钮是 24px 圆形，绿底白字=选中，灰字浅底=未选，可各自独立开关
- 开/关按钮：开=绿底白字，关=灰字浅底；关掉后整个网格消失，档位状态保留

【JS】
- 状态：gridOn（总开关）+ gridLayers{128,32,8}（档位）
- 档位表 GRID_TIERS=[[128,'rgba(51,51,51,1)',1],[32,'rgba(51,51,51,0.45)',1],[8,'rgba(51,51,51,0.2)',1]]
- gridStyle() 重建背景：每层两条 gradient（横+竖），按开关状态拼接
- 导出 setGridOn(v) / toggleLayer(v)，改状态后重绘

【验收】
- 8px 小格肉眼可数、32px 中格可对齐卡片间距、128px 大格可对齐区块边界
- 网格默认开启；面板操作不触发页面重排
```

---

## 设计意图（为什么这么定）

- **左上零线**：所有对齐测量从页面左上角起算，跟 getBoundingClientRect 的坐标一致，量出来就是格子数。
- **疏实密淡**：三层叠放时大的必须压过小的才可读；同 1px 线宽靠透明度分层。
- **pointer-events:none**：网格是测量工具，绝不能挡鼠标，否则原型交互全废。
- **选层制 + 独立档位**：做卡片对齐只需要 8/32，看区块只要 128——按需开，别糊一脸。
- **右下角固定**：不占内容流位置，翻页不遮挡左上内容区。

## 复用时调整点

| 场景 | 改什么 |
|------|--------|
| 只要对齐卡片 | 默认只开 8+32，关 128 |
| 深色原型 | 网格色改 rgba(255,255,255,…) |
| 要量出数值报告 | 加一个读数框：鼠标悬停显示当前 8px 格坐标 |
| 移动端原型 | 面板缩小，档位只留 8/32 |
